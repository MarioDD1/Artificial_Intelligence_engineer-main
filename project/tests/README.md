# Тесты проекта

Тесты запускаются из папки `project`:

```bash
python -m pytest tests
```

Проверяется:

- генерация данных и ожидаемые колонки;
- допустимые значения категориального признака `contract_type`;
- обучение пайплайна и наличие метрик финальной модели.
- работоспособность `/health` и `/predict` через `FastAPI TestClient`.
