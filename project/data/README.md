# Данные проекта

В папке лежат синтетические обезличенные данные для проекта ChurnGuard.

- `churn_train.csv` - основная выборка на 1200 строк для обучения и тестирования.
- `churn_sample.csv` - первые 20 строк для быстрой демонстрации формата.

Данные генерируются командой:

```bash
cd project
python -m src.data
```

В данных нет персональной или конфиденциальной информации. Целевая переменная `churn` принимает значения `0` и `1`.
